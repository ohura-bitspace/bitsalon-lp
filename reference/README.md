# 参考資料

LP の実装時に内容・配色の参照元とした既存の販促物です。**ビルド対象ではありません**（`public/` の外にあるため公開されません）。

| ファイル | 内容 |
|---|---|
| `bit-salon-brochure.html` | 4ページ構成のサービス資料。機能説明のコピー・トーンの参照元 |
| `bit-salon-flyer4.html` | A4チラシ。サービス資料の要約版 |
| `BITSALON.pdf` | 上記の書き出しPDF |

## 注意: 価格は古い

これらの資料に記載された料金（エントリー ¥3,300 / スタンダード ¥5,500 / プロ ¥9,900、いずれも税込）は**旧価格**です。

LP に掲載している最新の料金は `salon-reserve-mobile` リポジトリの
`src/admin/features/settings/AdminPlanSettings.jsx`（`PLAN_GROUPS`）を参照元としています。
価格を変更する際は、そちらとこれらの販促物の両方との整合を確認してください。

## LP に載せていない訴求要素

資料には含まれるが、LP のスコープ外として意図的に除外したものです。

- ホットペッパービューティー連携（プロプラン）
- モニター店舗募集（プロ機能を月額 ¥5,500 で提供）
- 紹介制度（1件紹介で月額 ¥1,500 割引・現金報酬）
