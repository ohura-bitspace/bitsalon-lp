## チラシの内容（2026-09-27 確認）

### 料金・プラン

チラシの月額料金は現行LPの `src/data/plans.ts` を基準にし、`salon-reserve-mobile/src/admin/features/settings/AdminPlanSettings.jsx` の `PLAN_GROUPS` と照合しました。紙面では個人・小規模サロン向け2プランと、複数店舗向けの開始価格を掲載しています。

| 現行プラン | 月額（税別） | 補足 |
|---|---:|---|
| スタンダード | ¥4,800 | 個人・小規模サロン向け |
| プロ | ¥9,600 | 個人・小規模サロン向け |
| ビジネス スタンダード | ¥9,000 | 2店舗込み。追加店舗は +¥4,000/月（税別） |
| ビジネス プロ | ¥18,000 | 2店舗込み。追加店舗は +¥8,000/月（税別） |

### 初期費用

導入内容に応じて **5,000円〜30,000円程度（税別）** の初期費用がかかり、申込み前に見積もりを提示する案内に更新しました。

### 掲載内容と連絡先

- 旧チラシにあったモニター特価、紹介制度、初期費用なし、契約期間の縛りなし、ホットペッパービューティー予約の自動取り込みに関する訴求は削除しました。ホットペッパービューティー連携はアプリのプロプラン機能一覧にはありますが、現行LPでは案内していません。
- 導入の流れは「相談 → 見積もり → 規約同意・申込み → アカウント発行後の支払い」に更新しました。契約条件の詳細は現行の利用規約を確認してください。
- 連絡先は `bitsalon.bitspace.jp` と `bitsalon@bitspace.jp` に更新しました。チラシ画像は `salon-reserve-mobile/docs/guide/admin-shots/a40-report.png` をコピーしたデモ画面です。

## ダウンロード用チラシを作る場合

HTML を A4・余白なし・背景色ありで PDF に書き出し、文字切れ・画像・リンクを確認してください。配布前に LP の `src/data/plans.ts`、アプリ側の `PLAN_GROUPS`、実際の課金設定と料金・条件を再照合します。完成した PDF を LP から配布する場合は `public/` に置き、LP にダウンロードリンクを追加してください。
