## 現行LP実装との相違（2026-09-27 確認）

### 料金・プラン

既存資料にはエントリー ¥3,300、スタンダード ¥5,500、プロ ¥9,900（いずれも月額・税込）が載っています。エントリープランは現行の料金表にはありません。現行LPの表示価格は `src/data/plans.ts` で定義し、`salon-reserve-mobile/src/admin/features/settings/AdminPlanSettings.jsx` の `PLAN_GROUPS` と照合しています。

| 現行プラン | 月額（税別） | 補足 |
|---|---:|---|
| スタンダード | ¥4,800 | 個人・小規模サロン向け |
| プロ | ¥9,600 | 個人・小規模サロン向け |
| ビジネス スタンダード | ¥9,000 | 2店舗込み。追加店舗は +¥4,000/月（税別） |
| ビジネス プロ | ¥18,000 | 2店舗込み。追加店舗は +¥8,000/月（税別） |

### 初期費用

既存資料の「初期費用0円」「初期費用なし」（`bit-salon-brochure.html` の 279・280・491 行目、`bit-salon-flyer4.html` の 119 行目）は現行の案内と異なります。現行LPでは、導入内容に応じて **5,000円〜30,000円程度（税別）** の初期費用がかかり、申込み前に見積もりを提示すると案内しています。

### そのほかの記載

- 既存資料のモニター店舗向け特別価格（月額 ¥5,500・税込）と紹介制度（1件あたり月額 ¥1,500 の割引など）は、現行LPでは案内していません。現在の募集・適用条件を確認せずに再掲載しないでください。
- ホットペッパービューティー連携はアプリのプロプランの機能一覧にありますが、現行LPでは訴求を絞るため掲載していません。公開用資料に載せるかは別途確認してください。
- 既存のサービス資料ではビジネスプランの価格を「お問い合わせください」としていますが、現行LPには価格を掲載しています。また、現行LPはクレジットカードと銀行振込の両方を案内しています。
- 既存資料の「契約期間の縛りなし」「解約金なしの月単位契約」といった表現や旧プランを前提にした機能説明は、現行の利用規約・LPと照合して書き直してください。利用規約には契約期間ごとの更新、解約、日割り返金なしの条件が記載されています。

## ダウンロード用チラシを作る場合

既存のHTML・PDFを価格だけ差し替えて公開せず、プラン構成、初期費用、機能、キャンペーン、契約条件を確認して作り直してください。料金は LP の `src/data/plans.ts` とアプリ側の `PLAN_GROUPS` を照合し、配布前に実際の課金設定とも一致することを確認します。完成したPDFをLPから配布する場合は `public/` に置き、LPにダウンロードリンクを追加してください。
